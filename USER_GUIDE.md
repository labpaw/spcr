# SPCR - Space Creator

Create beautiful, minimalist webpages in seconds. Design your perfect space with profile pictures, text, and social links - all with Figma-like smart alignment guides.

## 🎯 What is SPCR?

SPCR (Space Creator) is a visual editor for creating tiny, elegant webpages. Perfect for:

- Personal portfolio pages
- Social link aggregators
- Artist/Creator landing pages
- Quick bio pages with socials
- Event announcements
- Link-in-bio pages

No coding required. Drag, drop, align, and publish.

## ✨ Key Features

### 1. **Visual Canvas Editor**

- Click anywhere to add elements
- Drag to reposition
- See changes in real-time
- Responsive percentage-based positioning

### 2. **Smart Alignment Guides** (Figma-Style)

- **Pink guides**: Show alignment opportunities
  - Center alignment
  - Left/Right edges
  - Alignment with other elements
- **Purple "=" guides**: Show equal spacing
  - Perfect for organizing social links
  - Distributes elements evenly
- **Soft snap**: Guides suggest, but you decide

### 3. **Multiple Element Types**

- **Text**: Create titles, descriptions, bios
- **Images**: Add profile pictures, logos
- **Shapes**: Add decorative circles, squares
- **Links**: Add clickable social media buttons

### 4. **Customizable Backgrounds**

- Solid colors
- Pre-designed themes
- Blur effects for depth

### 5. **Quick Alignment Toolbar**

- One-click alignment buttons
- Center, left, right positioning
- Top, middle, bottom positioning
- Located on the right edge of screen

## 🚀 Getting Started

### Adding Elements

1. **Click anywhere on the canvas** → Type selector appears
2. **Choose element type:**
   - **Text**: Type your content
   - **Image**: Upload or paste URL
   - **Shape**: Choose circle or square
   - **Link**: Add social media buttons

### Positioning Elements

1. **Drag** any element to move it
2. **Watch for smart guides:**
   - Pink vertical/horizontal lines = alignment
   - Pink "Center"/"Middle" labels = centered
   - Purple "=" = equal spacing achieved!
3. **Release** when positioned

### Fine-Tuning Position

1. **Select** the element (click once)
2. **Open** alignment toolbar (tab on right edge)
3. **Choose** alignment:
   - **Horizontal**: Left, Center, Right
   - **Vertical**: Top, Middle, Bottom

## 🎨 Smart Guides Explained

### Alignment Guides (Pink Lines)

**Vertical Lines (Left-Right)**

```
        │ Center
        │
Photo ──┼── Text
        │
       Links
```

Appears when element is within 3% of:

- Canvas center (50%)
- Another element's position
- Left edge (5%)
- Right edge (95%)

**Horizontal Lines (Top-Bottom)**

- Same as vertical, but for vertical positioning
- Perfect for lining up elements in rows

**Snap Behavior:**

- Element snaps when within 3% threshold
- You can still drag past the snap point
- Snap is soft - it's a suggestion, not a lock

### Spacing Guides (Purple Lines with "=")

```
 ┌──────┐  ═════  ┌──────┐  ═════  ┌──────┐
 │Link 1│    =    │Link 2│    =    │Link 3│
 └──────┘         └──────┘         └──────┘
```

Appears when:

1. Dragging element with 2+ other elements on same row
2. Creating equal gaps between elements
3. Your element gap = reference element gap

**Perfect for:**

- Social link buttons
- Feature cards
- Navigation items

## 🎯 Alignment Tips

### Centering Everything

1. Select element
2. Open toolbar (right edge tab)
3. Click "Center" (horizontal)
4. Click "Middle" (vertical)
   ✨ Element is perfectly centered!

### Aligning with Other Elements

- Drag element near existing element
- Watch for pink "Align" guide
- Release to snap into place

### Equal Spacing (3+ Elements)

- Position first two elements
- Drag third element
- Watch for purple "=" guide
- Release for perfect spacing

## 🐛 Troubleshooting

### Element Won't Move

- Is it locked? Right-click → Check lock status
- Try double-clicking canvas to clear selection
- Refresh page if stuck

### Image Not Appearing

- Check URL is correct
- Images must be publicly accessible
- Try different image format (JPG, PNG, WebP)

### Guides Not Showing

- Elements might be too far apart (>3%)
- Make sure you're dragging (not clicking)
- Try moving element closer to center/edges

### Position Reset After Reload

- Page auto-saves to browser storage
- Clear browser cache to reset
- Try private/incognito window for fresh start
